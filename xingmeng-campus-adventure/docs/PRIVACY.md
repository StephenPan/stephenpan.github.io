# 隐私与儿童信息

1. 游戏默认**不需要帐号**，不采集真实姓名、班级学生名单、真实头像、学校地址或位置；出现的同学和老师均为虚构角色。
2. 题目表现、错题、班级印章等由浏览器 `localStorage` 保存；无需远端服务。关闭浏览器后存储通常保留，但无痕模式、清理浏览器或更换文件地址可能造成丢失。
3. 通过游戏内「成长档案 → 导出成长记录」或「学习设置 → 备份存档」获得 JSON 文件；该文件属于个人学习信息，**不得提交到公开 GitHub 仓库**。
4. GitHub Pages 是面向公众的静态网站，更新后的代码公开，但不会自动同步已有玩家的本地答题成绩。
5. 所有新版本要测试存档读取和升级策略，避免丢失进度。现有备份的导入支持受支持格式，并进行基础验证。
6. 未来若引入真实人物照片、语音、帐号或远程数据，需要新增专门的隐私和安全审查；本版没有这些功能。
