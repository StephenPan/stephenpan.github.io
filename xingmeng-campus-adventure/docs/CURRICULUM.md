# 二年级上学期学习设计 · v0.6

## 学习范围（针对常见中国大陆小学教材的一般知识范围，而非某一版教材逐题同步）

- **语文**：字形部首、近反义词、量词、词语搭配、基础标点、短句理解、动作顺序、小段阅读和观察表达。
- **数学**：100以内加减（基础与进退位）、表内乘法入门、长度单位厘米/米、角的初步认识、简单两步应用题。
- **科学兴趣**：生活科学、天气和物质观察、简单航空航海常识、实验安全、基础天文、元素符号和元素周期表兴趣卡。
- **未纳入当前主线**：分数、小数运算、方程、排列组合、复杂几何周长、化学反应配平和高中物理等内容。

## 适应策略

每个学科单独保存三个难度档：

1. **巩固基础**：短题干、单步思考和基础词语。
2. **标准练习**：进位/退位、简单两步应用和阅读理解。
3. **轻度拓展**：仍在二年级可理解的应用题和观察推理，不跨年级。

初始每个学科都是第1档；最近 14 道题首次答对率 ≥ 86% 时提升1档，≤ 43% 时降低1档，中间保持不变。每次升降会清空这一短期判定窗口；答错后可看提示、再次作答且不会损失金币或星星。游戏通过 `localStorage` 记录累计答题数、分学科首次答对率、错题、复习完成状态、班级印章和安全冒险进度。

**初始模式：** 标准练习节奏 + 温和石怪。家长可选轻松/标准/轻度挑战。当前版本不自动从二年级上学期切换到其他学段。

## 难度与游戏挑战

- 进入游戏每60分钟出现一次12题主线；不鼓励为了刷新题目长时间连续游玩。
- 22班各8题，老师通过后领取印章；科学兴趣挑战可以打开元素图鉴慢慢探索。
- 石怪用警示、追逐、星光消散、重新站位及救援任务构成挑战；无血腥、无永久死亡，不因碰撞损失学业记录。
- 建议连续游玩约15–25分钟后休息，游戏每25分钟提供一次休息提醒。

## 题目审核原则

1. 确认答案唯一、选项不重复、答案与解析一致。
2. 题干尽量短、语言通俗，减少年龄不适当的术语。
3. 科学兴趣题不要求危险化学操作和直接接触未知物质。
4. 正确率不是孩子能力的完整评价，不与其他儿童排名。
5. 未来引入新学段题库时，先经家长选择并考虑教材版本差异。
