  • CoinGecko public API：实时价格、Market Cap、FDV、24H/7D/30D 变化；market_chart 用于历史价格与市值。
  • DefiLlama PUMP fees API / Hyperliquid fees API：Revenue 历史；dailyHoldersRevenue 用于 30D 与季度回购/价值捕获聚合。
  • pump.fun 官方 PUMP Token 页面：50% revenue target、累计买回/销毁与 supply offset。官方页面截至 Aug 22 显示累计买回销毁 $435.32M / 161.49B PUMP。
  • Hyperliquid 官方 Fees 文档：Assistance Fund fee flow；HyperEVM 文档：HYPE 为 gas token、base/priority fees burn。
  • 市场份额不做错误横比：PUMP 的分母是 launchpad，HYPE 的分母是 perp DEX。fallback 分别来自 2026-08-09 的 98% tracked launchpad revenue share 与 DefiLlama 近期 30D perp peer-set 68.5%。
第三方公共 API 可能受 CORS/限流影响。失败时页面继续显示带日期的内置快照，并把状态灯改为黄色；不会把 fallback 伪装成实时数据。
